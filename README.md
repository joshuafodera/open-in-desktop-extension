# Open in Desktop

Click the toolbar icon to try opening the current page in its desktop app.
Pages load normally; nothing happens unless you click.

Install: chrome://extensions → Developer mode → Load unpacked → this folder.
Pin the icon. Chrome asks "Open X?" once per app; tick "Always allow".

Badge: ↗ fired · — no mapping · ? mapped but scheme not filled in.
Add apps in rules.js.

Test rules: `node test.mjs`.
